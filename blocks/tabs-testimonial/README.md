# tabs-testimonial

Custom **tabs** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: 2 cells: [tab: avatar image, name (bold), role] | [panel: image, name (bold), role, quote paragraph].

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
